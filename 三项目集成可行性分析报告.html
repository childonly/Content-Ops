目标项目：Content Ops Hub（内容运营中枢）

核心结论：三个项目中，已开源 Humanizer-zh（MIT, 10k+ stars）和 guizang-social-card（AGPL-3.0, 3.5k+ stars）均为 GitHub 开源项目，可直接集成；未找到独立仓库 Script Writer 并非一个独立开源项目，而是一个功能概念，需要基于现有 LLM 链自研实现。三者的集成将补全内容创作管线的"脚本化→拟人化→卡片化"最后一公里。

Script Writer 搜索结论

对 "Script Writer" 进行了多轮 GitHub 和中文技术社区搜索，未找到一个名为 "Script Writer" 的独立开源仓库，其描述的功能（将图谱节点转化为时间线叙事、分镜、旁白、台词，为视频平台流量逻辑优化节奏）与以下项目有部分重叠但均不完全匹配：

  • broadcast-script-writer：分段广播脚本创建工具，侧重时间标记，不含图谱节点转化
  • 字节开源 StoryMem：多镜头长视频生成框架，侧重视频生成而非脚本编写
  • 各 Coze/Agent Skill 中的"短剧剧本转视频提示词"工具：功能碎片化，非独立项目

结论：Script Writer 更可能是一个功能概念描述，需要基于本项目现有 LLM 链 + 视频工作室能力自研实现，而非直接引用某个开源仓库。

依赖冲突 无冲突 零外部依赖，仅依赖 LLM 调用能力，本项目已具备
集成模式 Prompt 注入 将 SKILL.md 中的 24 种 AI 写作模式规则注入为 system prompt，在 LLM 生成内容后做二次"拟人化"改写
许可协议 MIT 允许商业使用、修改、分发，无传染性限制
维护状态 活跃 2026年1月最新提交，10k+ stars，社区活跃

收益评估

  • 功能增益：补全内容管线的"拟人化"环节，将 AI 生成内容从"机器味"提升到"可发布"质量
  • 用户体验：减少用户手动修改 AI 内容的工作量，预计减少 60-80% 的后处理时间
  • 开发成本：极低，仅需将 SKILL.md 规则集成到现有 LLM 调用链中
  • 运行成本：零额外成本，复用现有 LLM 提供商链

风险评估

  • 改写质量风险：LLM 可能过度改写导致语义偏移 → 缓解：保留原文对照，用户可选择接受/拒绝
  • 平台适配风险：当前 24 种模式为通用规则，未针对 B站/抖音/小红书分别优化 → 缓解：后续可扩展平台专属规则

综合建议

强烈推荐 ⭐⭐⭐⭐⭐

零成本、零依赖、高度互补，是三个项目中投入产出比最高的集成目标。

功能拆解

子功能说明现有基础

旁白撰写为每个镜头生成配音文本，控制语速和节奏LLM 链已有内容生成能力

图谱节点转化将知识图谱/内容大纲节点映射为时间线叙事结构首页 Vue Flow 流程图已有 DAG 可视化

匹配度分析

分析维度评估结果说明
功能匹配 战略补充 当前视频工作室仅支持"转录→内容创作"，缺少"内容→视频脚本"的反向链路。Script Writer 补全了 内容创作 → ❌缺失 → 视频脚本 → 视频制作 这条管线
技术栈匹配 完全兼容 基于现有 LLM 链实现，无需额外技术栈。Vue Flow 已有图谱可视化基础
依赖冲突 无冲突 纯 LLM + Prompt 工程，零外部依赖
开发成本 中等 需新建脚本模板系统 + 平台节奏规则 + 前端脚本编辑器
许可协议 无限制 自研代码，无协议风险

自研技术方案

核心思路：将 Script Writer 实现为一个 LLM Prompt 模板 + 前端脚本编辑器，集成到视频工作室中。

  • Prompt 模板：为 B站/抖音/小红书视频分别设计脚本生成模板，包含 Hook 结构、节奏控制、CTA 规则
  • 输入：内容工作室生成的小红书笔记内容 / 视频转录稿 / 手动输入的大纲
  • 输出：JSON 结构化脚本（分镜表：序号、画面描述、旁白、台词、时长、转场）
  • 前端：在视频工作室新增"脚本创作"Tab，展示分镜表 + 可编辑 + 导出功能

综合建议

推荐自研 ⭐⭐⭐⭐

虽无现成开源项目可直接集成，但基于现有 LLM 链 + 视频工作室架构自研成本可控，且能精确匹配项目需求。

七、总结

三者形成完整的内容创作-发布闭环，每个环节都补全了当前项目的关键缺口。建议按 P0→P1→P2 优先级分阶段实施，总预估工作量 18-25 人天。
