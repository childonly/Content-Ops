# 内容工作室节点工作流设计

## 背景

当前项目已经具备趋势发现、标签研究、内容生成与编辑、配图、质检、审核、发布、数据追踪和业务流编排能力，但这些能力分布在多个页面和多个按钮中。用户需要记忆模块顺序、反复切换页面，并自行判断下一步动作。

本设计引入一层“内容工作流视图”，复用现有 API、路由和业务模块，不重写现有能力。目标是让用户围绕一个内容对象逐步添加节点完成任务，同时保留现有页面作为高级入口。

## 核心流程

默认模板为：

`趋势发现 → 选题确认 → 标签研究 → 内容生成 → 人工编辑 → 配图 → 质检 → 审核 → 发布 → 数据追踪`

节点只表示编排和状态，不复制内容数据。节点通过 `trendId`、`contentId`、`pipelineRunId` 等现有字段引用业务对象，执行时调用既有 API。

## 节点与可用动作

节点分为六类：

- 输入：趋势、关键词、已有草稿或外部素材。
- 研究：趋势发现、标签研究、竞品/评论分析。
- 生成：标题正文、改写、摘要、配图、视频脚本。
- 人工：编辑、选择、审核、确认发布。
- 动作：保存草稿、加入发布队列、立即发布、定时发布。
- 观察：发布结果、互动数据、复盘建议。

右键菜单由“当前节点状态 + 已有数据 + 引擎能力”计算，不写死在组件中。例如：

| 当前状态 | 推荐下一步 | 可选动作 |
| --- | --- | --- |
| 已选趋势 | 标签研究、生成草稿 | 删除、加入收藏、查看详情 |
| 已有草稿 | 编辑、配图、质检 | 复制、归档、重新生成 |
| 已通过审核 | 发布、定时发布 | 回退编辑、复制渠道 |
| 已发布 | 数据追踪、复盘 | 查看笔记、再次分发 |

不可用动作必须显示原因，例如“尚未登录小红书”“缺少正文”“没有可用图片引擎”，而不是让用户点击后才看到通用错误。

## 交互方案

1. 画布显示当前内容对象的节点链，节点上只保留状态、摘要和一个主动作。
2. 点击节点打开右侧检查器，展示输入、输出、运行记录和高级配置。
3. 右键节点显示“推荐下一步”和“更多操作”；选择后自动创建下一个节点并带入上游引用。
4. 新节点默认使用项目推荐配置，复杂参数收纳到“高级配置”，不阻塞主流程。
5. 节点执行失败时保留失败节点和错误原因，支持“重试”“修改配置后重试”“跳过（需确认）”。
6. 旧页面的按钮继续保留；从旧页面创建或打开内容时，可一键切换到对应工作流节点。

## 与现有业务流的关系

项目已有 `business_flows` 的 nodes/edges 持久化、CRUD 和拓扑执行接口，可作为节点工作流的底层存储与执行框架。第一阶段只增加内容工作流模板和动作能力映射，不改变现有节点类型、路由或字段名；后续再按需要增加节点运行状态、输入输出快照和恢复点。

## 分阶段实施

- P0：完成趋势删除和登录可用性修复，明确真实/模拟引擎状态。
- P1：在内容工作室增加只读流程条、节点状态和右键推荐动作，不改变现有执行逻辑。
- P2：将推荐动作连接到现有趋势、内容、配图、审核、发布 API；支持自动添加节点和失败重试。
- P3：增加模板、分支、定时节点、断点续跑和运行记录；逐步减少旧页面中的重复配置。

## 方案 A 补充：编排中心体验与可观测性

本次按“流程优先 + Tapnow 式渐进增强”落地，保持现有 DOM 语义、路由、接口字段和业务页面兼容。

### 画布交互

- 拖放节点时使用画布坐标转换，节点落在鼠标释放位置。
- 中键双击采用智能定位：有选中节点时定位选中集合；无选中节点时定位最近新增节点；没有新增节点时适配全部节点。
- 支持 Shift/Ctrl 多选和框选，提供“已选 N 个”工具条，批量移除时一次确认，并同步移除关联边。
- 右键从直接删除改为上下文菜单，展示推荐下一步、配置、查看运行结果和移除等动作。

### 运行结果

- 执行接口返回的运行编号、整体状态和逐节点步骤结果必须进入“运行详情”抽屉。
- 新增 `business_flow_runs` 与 `business_flow_step_runs` 表，只做追加式迁移，保存输入/输出快照、状态、耗时、错误和重试信息。
- “我的流线”增加最近运行状态、查看详情和失败重试入口；画布节点显示未执行、执行中、成功、失败和模拟状态。
- 现有 Skill/Module 模拟执行必须明确标记为“模拟”，真实业务适配以节点适配器方式逐步接入。

### LLM 模型

- 每次分析/对话返回 provider、model、duration 和 fallback 信息，前端显示实际使用模型。
- LLM 节点提供“本次调用”模型选择，并可选“设为当前编排默认”；解析顺序为本次选择 → 编排默认 → 模块默认 → 系统自动。
- API 密钥只在服务端读取，前端不展示密钥内容。

### 信息架构

侧边栏按工作顺序重组为“工作台、内容生产、自动化、数据洞察、系统设置”，旧路由继续可访问并通过重定向/别名兼容。实施先完成编排与运行可观测性，再收敛重复入口。

## 验收指标

- 新用户从趋势到草稿只需沿推荐动作前进，不必记忆页面顺序。
- 每个节点只有一个主动作，其他动作集中在右键菜单/检查器。
- 业务 API、字段和原有页面回归测试保持通过。
- 节点菜单不会推荐当前引擎不可用或前置条件未满足的动作。
