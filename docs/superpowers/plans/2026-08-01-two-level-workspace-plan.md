# 两层工作台实施计划

## P0：工作台基础能力

1. 最近编排卡片增加删除操作，处理选中项和路由回退。
2. 修复业务流删除的引用检查和错误反馈。
3. 建立前端能力目录，实现右键候选、自动新增和自动连线。
4. 修复 Vue Flow 节点到服务端节点契约的标准化。

## P1：项目运行底座

1. 新增 `project_workflows`、`project_workflow_nodes` 表及索引。
2. 新增项目工作流 CRUD、单节点执行、确认结果、重试和连续执行 API。
3. 建立适配器注册中心，先接趋势、标签、内容、审核和待发布节点。
4. 节点结果保存直接输入/输出、来源、模型、耗时和错误，不保存递归上下文。

## P2：第二层画布

1. 工作台增加“业务编排 / 项目工作流”层级切换。
2. 新建项目时选择业务编排并填写初始输入。
3. 实现项目节点画布、状态节点、结果检查器和提示词微调。
4. 实现“执行当前节点”“确认并进入下一步”“连续执行”。
5. 实现底部运行时间线和待发布成果区。

## P3：引擎中心

1. 将默认图片模型和文案切换为 CogView-3-Flash。
2. 修复图片默认引擎持久化与不可用默认值问题。
3. 增加 LLM 快速切换与健康状态。
4. 增加未安装引擎的配置说明、环境变量和检测结果。

## P4：内容数据真实性

1. 修复 Radar 趋势分组响应与前端扁平列表不一致。
2. 增加趋势详情、来源 URL、原始 ID、采集时间和 observed/estimated 标识。
3. 标签搜索适配 `{ query, results }`，增加详情和来源。
4. 移除随机指标伪装；无法获得真实指标时明确显示“估算/无数据”。

## P5：自动化 CRUD

1. 闭环运行表增加多选、详情、编辑、单删和批量删除。
2. 服务端增加批量删除和允许编辑的运行元数据接口。
3. 小红书流水线运行/草稿列表统一补齐多选与删除反馈。

## 回归

- 单元测试覆盖节点标准化、推荐候选、项目删除引用、节点适配器和响应映射。
- API 回归覆盖项目工作流全生命周期、趋势/标签详情和自动化批量操作。
- 前端回归覆盖深浅主题、项目切换、右键菜单、节点执行、重试、最终待发布和旧页面兼容。
